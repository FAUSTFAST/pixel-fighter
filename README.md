# Pixel Fighter · 像素格斗

原生 JavaScript / Canvas 本地格斗游戏，无需 npm 依赖。双击 `启动游戏.command` 启动后台服务并打开游戏；也可运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/?v=air-style1`。

## 跳跃与其他动作的形象一致性修正

保留原始像素素材。六名角色的空中动作沿用站姿比例，以逐帧髋部标记定位身体，收腿和踢腿不再用脚的位置牵动整个人物。跳跃按竖直速度选择伸展、收腿、下落姿势，离地后不再播放蹲地蓄力；越过对手时保持起跳朝向，落地后再转身。

普通落地使用浅屈膝衔接，空中拳脚与发射招式使用空中姿势。踢击、必杀和受击图集改用站立收招帧校准尺寸，避免蹲姿或武器高度改变人物比例；发射与投技的有效阶段对应释放帧。同页动作图鉴增加朝向选择和跳跃轨迹开关，可对照站姿慢放。

运行 `node scripts/check-animation-consistency.cjs`：六名角色、132 段素材动作、16,920 次动作选帧检查通过，覆盖角色归属、空中定位、跳跃阶段、落地、空中出招与释放帧，并检查越人时的朝向。资源目录重新编目成功。浏览器工具未能取得当前标签页，因此尚未完成浏览器实战画面确认。

## 原画风恢复与移动稳定性修正

六名角色恢复与原版站姿一致的 `animation-v7/<id>-walk.png`，前进、后退各 8 张姿势。上一版独立重绘的 12–16 帧移动素材因画风和身材比例不一致，已退出运行目录。当前使用 42 张图集、132 段动作、672 张姿势；保留此前已修正的角色专属拳脚、必杀与受击形象。

保留下表的慢走速度、起步加速和 4–10 帧收脚。步态在双方身体碰撞处理后，按自身实际前进距离推进，排除对手推挤；短暂停步再起步保持原步态，不反复跳回第一张图。跳跃、攻击与受击可以打断步态。朝向在采集输入前统一决定，电脑不再重复改写朝向；交叉时保留小范围容差，防止临界点左右闪动。

恢复原来的 2 倍像素缓存，图帧绘制尺寸与锚点统一到同一像素网格，减少朝左镜像时边缘抖动。移动图帧按逐帧髋部标记对齐身体中心、按支撑脚对齐地面，去除图集排版造成的左右偏移。原图透明通道原样保留，不修改图片。页内「出招表 → 街机动作图鉴」选择「稳步前进 / 稳步后退」，可对照站姿并查看实际绘制帧数。

当前素材由 `assets/characters/animation-v7/identity-lock.json` 固定。本次复用原始素材并重新编目，未生成新图，也未新增或运行自动化测试。

**出招表 → 街机动作图鉴** 增加「站姿对照」和「受击闪光」，所有操作仍在当前游戏页面内。修正素材保存为 `assets/characters/animation-v7/*-identity-v1.png`；完整提示词与参考图列表见该目录的 `identity-prompts.json` 和 `identity-extra-prompts.json`。

## 街机动作重绘 v7 与距离配置

使用内置 imagegen 重新绘制街机关键姿势，按固定脚底锚点和固定身体比例播放。新图集位于 `assets/characters/animation-v7/`，六名角色均已完成 7 组 4×4 图集：前进 / 后退、站立 / 蹲姿 / 防御、前跳 / 后跳 / 空中拳脚、拳、脚、必杀、受击。`manifest.json` 由透明连通区域生成，资源缺失时仍会安全回退，不会让选角或进入战斗卡住。

`js/arcade-animation.js` 直接播放新姿势，按透明区域分离相邻图帧，所有动作共用角色脚底和根节点。`js/motion60.js` 继续提供 60 Hz 招式时间轴；图帧只表达姿势，攻击距离、命中时间和特效仍由战斗逻辑控制。资源未齐时会回退到原有移动 / 拳脚图集，避免出现空白角色。

走路随真实位移推进步频，后退使用独立朝敌姿势；松开方向后原地完成 4–10 个逻辑帧的收脚，攻击可以立即打断收脚。`js/combat-spacing.js` 定义步行、攻击范围与突进距离。

拳脚的水平覆盖增加约 20%–35%，必杀的打击面积和弹体尺寸扩大。拳脚高度按角色当前身高校准，命中框、末端效果、图鉴范围和出招表使用同一几何数据。投技维持近身距离。飞行道具按刀刃、雷枪、月牙等形状计算碰撞范围。

## 当前版本：经典 / 现代连招体系

参考 Capcom 官方介绍的经典六键、现代方向＋SP、Assist 辅助连段与独立斗气资源，按本作角色、画面尺度和 60 Hz 战斗逻辑实现。招式、数值与连段路线为本作原创；不是 SF6 的完整逐帧复刻。基础动作优先使用 v7 新绘图集，专属招式结合已有角色差异化动作、独立判定和特效。

### 手柄

连接 USB / 蓝牙手柄后，点击游戏页面，再按一下手柄按钮并松开。右上角「连接手柄」可打开连接状态、P1 / P2 分配、死区和完整键位。接口按 [W3C 标准手柄布局](https://www.w3.org/TR/gamepad/#remapping)实现；非标准设备使用标准索引回退，按键不对应时需切换 XInput 模式或使用能识别该设备的浏览器。

- 前两个连接的手柄分别控制 P1 / P2；可以在设置里交换，或把一个手柄分配给 P2，与 P1 键盘对战。断开一个手柄不会自动改动另一位玩家的分配。
- 十字键 / 左摇杆支持移动、跳跃、蹲防和方向搓招；摇杆死区默认 25%，可调为 15–50% 并保存。
- 菜单 A / × 确认，B / ○ 返回；Start / Options 暂停 / 继续；View / Share 打开设置；暂停时 Y / △ 打开出招表。
- 页内设置上下移动焦点，左右更改选项 / 数值，A / × 点击，B / ○ 关闭。进入新界面或重连后松开按键再操作。
- 断线或失去窗口焦点会暂停对战、清空输入。重新连接后主动按 Start 继续。

方向相对面向。拳 / 脚可选轻中重，普通必杀三个强度影响起手、伤害、弹速。

| --- | --- | --- |

### 连段规则与资源

- 普通技之间使用各角色的目标连段、轻攻击连打或收招后的目押连接，取消窗口为接触后 10 帧；普通预输入保留 8 帧。
- 可取消普通技在命中 / 被挡后接必杀、SA 或斗气冲刺。挥空不能取消；扫腿不可取消；投和反击架势不能取消接入。
- 普通必杀可取消 SA3；OD 必杀可取消 SA2 / SA3；超必杀不再取消其他攻击。
- SA 槽上限 300，SA1 / SA2 / SA3 消耗 100 / 200 / 300。普通必杀免费，取消旧版自动耗 50 气和弱化波规则。
- 六格斗气：OD 2 格，普通技接触取消冲刺 3 格，自由冲刺 1 格，斗气迸放 1 格。冲刺后的第一个普通技增加 4 帧命中 / 防御硬直。
- 经典中拳＋中脚或招架键可保持招架；招架中前前可冲刺。普通技接触后前前 / 中拳＋中脚或冲刺键可取消冲刺。重拳＋重脚或迸放键发动两段霸体重击。
- 斗气耗尽时禁用斗气技，防御硬直增加 4 帧，必杀防御会削血；恢复满六格后解除耗尽。
- 后方向站防，下后蹲防；单独下蹲不格挡。下段需要蹲防，中段破解蹲防。普通投可在被抓后 7 帧内拆投，指令投不能拆，也不能抓受击或防御硬直中的对手。
- 连段每追加一次命中递减 10% 伤害，最低 20%；SA1 / SA2 / SA3 的最低伤害比例为 30% / 40% / 50%。普通地面打击保持站地受击，击倒技和对空技有独立效果。
- 现代辅助：按住辅助后连按轻 / 中 / 重，**每次按下只推进一招**；必须继续输入，不会自动打完整段。预输入等待合法衔接时机；挥空、受击、资源不足会中断，未命中时不自动花资源接 OD / SA。松开辅助会清除待执行的辅助输入。

## 模式与训练

首页：双人对战、电脑对战、训练模式、设置。普通对战三局两胜，电脑提供简单 / 普通 / 困难。训练无限时间，玩家主动退出，血量归零后按配置恢复。

训练设置可选择双方角色、七张地图、血量 1–999、SA 0–300、斗气 0–6、无敌，以及木桩或三档电脑。点击「应用并继续训练」生效。训练 HUD 显示模式、动作帧、取消提示、连击数与伤害。所有界面均在同一页面内，设置中可返回首页。

## 美术与舞台

六名像素角色使用 4×4 基础图集、32 帧前后移动 / 跳跃图集，以及 16 帧踢击 / 投技图集。角色显示和碰撞按原版两倍放大，行走速度按上表区分前进与后退。素材加载失败使用程序绘制回退。

七张 1440 宽幅舞台：古武道场、霓虹夜街、落日海滩、熔岩神殿、雨夜车站、雪山神社、空中庭院。960×540 视口随双方平移，地图延伸使用统一风格的新场景内容。场景包含飘花、雨丝、飘雪、波光、霓虹牌与人群等装饰动画，不参与碰撞。

美术预览：`art-preview.html`。素材提示词：[assets/README.md](assets/README.md)。

### 舞台音乐

七张地图各有原创主题，使用本地 Web Audio 合成乐器，无需联网下载音乐。每首为 32 小节循环：4 小节引入、8 小节主段、8 小节副歌、4 小节间奏、8 小节强化副歌；包含独立旋律、和声、低音、鼓组与过门。`js/soundtracks.js` 保存乐谱，`js/audio.js` 负责配器及基于音频时钟的前瞻调度。切换舞台时旧音轨淡出并回收节点。
