## 连招与压制重新平衡

重新定义六名角色的九种普通技的发生、持续、收招、命中硬直和防御硬直。轻拳发生 4–5 帧，早期命中优势 +2F、被挡 -3F；收招后再接轻拳有防守空隙。三种轻攻击可以互相连打，合计最多三招，替换按钮不能重置次数。命中与格挡产生推开，场边吸收的位移转给进攻方，防止角落消除推开距离。疾风与美琳的非 OD 多段突进中版末段优势为 0F，轻版 +2F、重版 -2F，避免“突进→轻拳→突进”免费循环。击倒落地后覆盖起身的受击保护，直到对手获得防御 / 反击机会；空中追击仍保留。

普通技取消使用角色专属目标连段和出招表允许的必杀 / SA / 冲刺；其他普通技只能等待收招后目押。疾风中拳 +5F 能接 5F 轻拳，不能接 7F 中拳；中拳→重拳是指定目标连段。美琳轻拳可以取消慢起手中段「燕掠踏肩」，但无法形成真连段。斗气冲刺下一普通技 +4F，可以打开新连接，同时承担资源消耗与后续伤害修正。铁拳轻辅助路线收尾改为快速上勾，避免旧慢波衔接留下空隙。

伤害按招式实例而非每一段递减，多段必杀与多发超必杀通过同一攻击 ID 共用修正。完整比例见下方「连段规则与资源」。训练 HUD 显示连段 / 断连、实际伤害修正、接触后的命中或防御帧差。页内和独立出招表增加发生 / 持续 / 收招以及命中 / 防御帧差；击倒和飞行道具不冒充固定地面命中优势。数值与修正组合针对本作角色和 100 HP 尺度设计，参考街霸 6 的连接、连打、目标连段、取消与递减思路，并非逐招逐帧复刻。

运行 `node scripts/check-combo-balance.cjs`：108 组角色与场景搭配，43,200 帧持续贴脸轻拳，检查三连上限、恢复防御与反击、场边推开；另检查 48 个普通技自连、正确 / 错误目押、慢 / 快必杀衔接、36 组辅助路线、22 种多段招式的修正、SA 保底与断连重置。报告保存在 `output/combo-balance/results.json`。原版动画对比见 `output/combo-balance/combo-links.gif`：左侧轻拳接重拳被挡，右侧中拳→重拳→三段螺旋掌真实五连，显示 100% / 90% / 70% 修正。

## 二段跳

六名角色、经典与现代操作均支持二段跳。起跳后松开跳跃方向，在空中再次按下即可发动：默认 P1 为 **W**，P2 为 **↑**；手柄使用十字键或左摇杆向上，第二次输入前先松开或回到中立。自定义跳跃键沿用设置。

每次主动离地最多两跳，落地、回合重置和训练重置恢复次数。第二跳的起跳速度为角色首跳的 80%，可在上升、顶点或下落时触发；同时输入左右方向可改变水平速度，不输入方向则保留惯性。第二跳重启空中动作，保持角色朝向，并显示短暂气环、提示和起跳音效。跳跃不消耗 SA 或斗气。

受击、倒地、被投和出招期间不能起跳；空中普通技收招后仍可使用尚未消耗的第二跳。上升必杀和被挑空不提供二段跳。这里采用本作的通用二段跳规则与原创数值。

运行 `node scripts/check-double-jump.cjs` 检查六名角色的 36 组方向与时机组合、键盘与手柄输入边沿、改键、经典 / 现代模式、不同刷新率、出招 / 受击限制及落地 / 回合 / 训练重置。动画一致性检查 `node scripts/check-animation-consistency.cjs` 也通过。手柄输入已模拟检查，未进行实体手柄实测。

### 躲波测试与动画回放

本地游戏服务启动后打开 [二段跳躲波回放](http://127.0.0.1:8765/jump-wave-test.html)。页面自动慢放，可切换站立、单跳和二段跳，暂停、逐帧推进、拖动时间轴、显示实际碰撞框，并查看命中与扣血结果。

使用实战的 `Fighter`、`Projectile`、招式配置和共用的 `Projectile.hitTarget()` 判定；不启用无敌或格挡，不改变弹体参数。默认测试为疾风对铁拳「地裂震拳」，相距 520 px；第 62 帧首跳、第 82 帧第二跳。站立与单跳均命中一次、损失 19 HP；二段跳零命中、零损失，波在第 113 帧完整通过，角色第 124 帧落地，交叉期间最小垂直间隔 46.2 px。另提供苍月「弦月剑气」的失败对照：第 28 / 48 帧两次起跳，仍在第 73 帧被命中、损失 17 HP。这是固定招式与输入时机的对照，不能推断所有波都能躲过。

运行 `node scripts/check-jump-wave.cjs` 重现结果并检查碰撞、格挡、无敌排除与弹体单次命中。`scripts/render-jump-wave.cjs` 使用 `@napi-rs/canvas` 调用游戏原版绘制，输出对比动画的 PNG 帧与结果到 `output/jump-wave-test/`；交付 GIF 位于该目录下的 `double-jump-wave.gif`。

## 电脑对战 AI：走位、确认与三档难度

电脑使用延迟观察到的角色动作与飞行道具决定防守，不读取玩家按键。六名角色有不同的距离偏好：美琳侧重近身压制，铁拳使用投技与霸体突进，闪电使用快速位移与雷枪，苍月保持剑术距离，贤者结合延迟控场与接近，疾风在试探与连段间切换。

远距离会交替前进、短暂试探、后撤和跳入；普通 / 困难还能用斗气冲刺接近。普通飞行道具有独立冷却，场上已有己方弹体时不继续发波，发波后还需实际走位才能再次发射。近身根据攻击范围选择拳脚、高低段、投技与角色专属技，减少重复招式；看到对手收招才增加惩罚权重。

命中确认按真实接触时刻延迟处理，只在合法窗口内接目标连段、轻攻击连打、必杀、OD 或 SA；被挡、挥空、受击与资源不足会停止连段追击。普通 / 困难有对空与躲波选择，二段跳不提供额外无敌。困难在角落会尝试后投换位，资源技仍使用玩家同一战斗规则。

| 难度 | 观察延迟（60 Hz） | 命中确认后的连续招式上限 | 主要体验 |
| --- | --- | --- | --- |
| 简单 | 23–31 帧，约 0.38–0.52 秒 | 2 招 | 反应慢、主动留空隙；不使用 OD 或斗气冲刺，偶尔确认 SA1 |
| 普通 | 12–17 帧，约 0.20–0.28 秒 | 3 招 | 走位试探、对空、命中确认，适量使用 OD / 冲刺 / SA1–2 |
| 困难 | 6–9 帧，约 0.10–0.15 秒 | 5 招 | 更快反应、收招惩罚、资源连段，可确认 SA3；仍可能判断失误 |

招式上限指连续取消的招式数，一招多段命中会显示更多连击。F2 中可随时调整电脑难度；训练中的三档电脑使用相同策略。运行 `node scripts/check-ai.cjs`：六角色 × 三难度共 32,400 个实战逻辑帧，检查走位、招式变化、发波限制、取消窗口与资源，并用 144 次相同雷枪试验比较三档防守。

## 跳跃与其他动作的形象一致性修正

保留原始像素素材。六名角色的空中动作沿用站姿比例，以逐帧髋部标记定位身体，收腿和踢腿不再用脚的位置牵动整个人物。跳跃按竖直速度选择伸展、收腿、下落姿势，离地后不再播放蹲地蓄力；越过对手时保持起跳朝向，落地后再转身。

普通落地使用浅屈膝衔接，空中拳脚与发射招式使用空中姿势。踢击、必杀和受击图集改用站立收招帧校准尺寸，避免蹲姿或武器高度改变人物比例；发射与投技的有效阶段对应释放帧。同页动作图鉴增加朝向选择和跳跃轨迹开关，可对照站姿慢放。

运行 `node scripts/check-animation-consistency.cjs`：六名角色、132 段素材动作、16,920 次动作选帧检查通过，覆盖角色归属、空中定位、跳跃阶段、落地、空中出招与释放帧，并检查越人时的朝向。当前 B 版恢复已完成真实 PNG 检查、原版游戏回放画面检查和隔离 Firefox 实测。

### 手柄

### 连段规则与资源

- 普通技之间使用各角色的目标连段、最多三招的轻攻击互相连打，或收招后的目押连接。普通技取消窗口为接触后 8 帧，必杀为 10 帧；普通预输入保留 8 帧。
- 出招表标记可取消的普通技在命中 / 被挡后接必杀、SA 或斗气冲刺。挥空不能取消；下轻脚只可轻攻击连打，扫腿不可取消；部分重脚不可取消必杀；投和反击架势不能取消接入。允许取消不保证连上，下一招发生太慢时对手可防御。
- 普通必杀可取消 SA3；OD 必杀可取消 SA2 / SA3；超必杀不再取消其他攻击。
- SA 槽上限 300，SA1 / SA2 / SA3 消耗 100 / 200 / 300。普通必杀免费，取消旧版自动耗 50 气和弱化波规则。
- 六格斗气：OD 2 格，普通技接触取消斗气冲刺 3 格，自由斗气冲刺 1 格，斗气迸放 1 格。斗气冲刺后的第一个普通技增加 4 帧命中 / 防御硬直。
- 经典中拳＋中脚或招架键可保持招架；招架中前前可冲刺。普通技接触后前前 / 中拳＋中脚或冲刺键可取消冲刺。重拳＋重脚或迸放键发动两段霸体重击。
- 斗气耗尽时禁用斗气技，防御硬直增加 4 帧，必杀防御会削血；恢复满六格后解除耗尽。
- 后方向站防，下后蹲防；单独下蹲不格挡。下段需要蹲防，中段破解蹲防。普通投可在被抓后 7 帧内拆投，指令投不能拆，也不能抓受击或防御硬直中的对手。
- 修正按攻击实例计算：普通起手 100% / 100% / 80% / 70%…，轻攻击起手 100% / 90% / 80% / 70%…；同一必杀的多段打击或多发弹体共用一档修正。普通最低 10%；SA1 / SA2 / SA3 最低 30% / 40% / 50%。下中脚起手使后续额外扣 20 个百分点，目标连段取消每次额外扣 10 点，斗气冲刺取消额外扣 15 点并沿后续连段累计。快捷输入的 80% 基础伤害仍独立计算。对手有可行动帧时断连，下一次命中恢复全伤害。
- 现代辅助：按住辅助后连按轻 / 中 / 重，**每次按下只推进一招**；必须继续输入，不会自动打完整段。预输入等待合法衔接时机；挥空、受击、资源不足会中断，未命中时不自动花资源接 OD / SA。松开辅助会清除待执行的辅助输入。

### 普通冲刺与后撤步

站在对手左侧时，P1 快速按 D → 松开 → D 前冲，A → 松开 → A 后撤步；站在右侧时相反。P2 使用对应方向键；手柄方向十字键 / 摇杆和自定义方向键通用，经典 / 现代相同。两次纯水平方向按下须在 18 个逻辑帧（0.3 秒）内，中间回到中立；斜向、长按、自动重复不会冲刺。冲刺只能在地面开始，最近 6 帧可预输入；空中输入不保留到落地。

普通冲刺不消耗斗气，耗尽时仍可使用，没有攻击判定或斗气增益，不能取消普通技。冲刺期间无法出招、跳跃、防御或招架；攻击可在最后 8 帧预输入，于收招后发动。后撤步整个动作期间免疫普通投与指令投，仍能被拳脚、下段与波击中；受击立即打断位移。遇敌与场边停止位移，但收招不缩短。朝向与移动方向在动作开始时锁定，越人不会折返。以下是适配本作地图与角色的原创数值，并非 SF6 原始帧数据。
