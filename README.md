# Pixel Fighter · 像素格斗

一个纯浏览器的横板格斗游戏(类似 Street Fighter / Guilty Gear),用 HTML5 Canvas + 原生 JavaScript 写成,**无需安装任何依赖**。

## 运行方式

直接双击 `index.html`(或用浏览器打开)即可开始。推荐 Chrome / Edge。

## 游戏内容

- **6 名角色**,各有不同属性与专属必杀:
  - 疾风(忍者·均衡,风刃远程)
  - 美琳(武者·敏捷,多段突进)
  - 铁拳(拳王·力量,上勾冲拳)
  - 闪电(少年·速攻,雷球)
  - 苍月(剑客·长距离,拔刀斩)
  - 贤者(法师·术法,大火球)
- **4 张地图**:古武道场、霓虹夜街、落日海滩、熔岩神殿
- **两种模式**:本地双人对战(同键盘)/ 挑战电脑(三档难度 AI)
- 三局两胜、血条、能量槽与必杀、格挡与消血、连招硬直、KO 与倒地、命中定格与震屏特效
- **连击/伤害反馈**:命中显示伤害数字,连续命中显示 HIT 连击数,格挡显示 BLOCK,弱化必杀显示 WEAK SPECIAL
- **暂停出招表**:对战中按 `P` 查看操作、搓招、音频开关状态与双方必杀说明

## 操作

| 动作 | P1 | P2 |
|---|---|---|
| 移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 下蹲 | S | ↓ |
| 轻拳 | F | J |
| 重拳 | G | K |
| 必杀(需半管气) | H | L |
| 确认 / 再战 | Enter | Enter |
| 返回 | Esc | Esc |
| 暂停 / 出招表 | P | P |
| 音乐开关 | M | M |
| 音效开关 | N | N |

**格挡**:向后(远离对手方向)按住方向键即为格挡,可挡下攻击并只受少量消耗血。
**攒气**:攻击命中、被击、格挡都会积累能量槽,满半管即可放必杀。

**搓招(指令输入)**:除了直接按必杀键,也可以像传统格斗游戏那样搓 **↓ ↘ →ㅤ+ 轻/重拳**(面向左时为 ↓ ↙ ←)释放必杀。
- 有半管气:释放**全力必杀**(消耗气,伤害/判定最强)
- 没有气:释放**弱化必杀**(不消耗气,伤害约 55%),让你随时有远程/突进手段。

**音效**:游戏用 Web Audio 程序化合成打击、格挡、必杀、KO、菜单音与逐地图不同的循环背景音乐,**不需要任何音频文件**。首次按键后自动解锁声音。

## 流程

标题 → 选择模式(双人/电脑)→(电脑模式选难度)→ 选角色 → 选地图 → 对战 → 结算(Enter 再战 / Esc 回标题)。

选角色:P1 用 A/D 移动光标、F 确认;P2 用 ←/→ 移动、J 确认;双方确认后自动进入选图。

## 代码结构

```
index.html          页面 + 脚本加载
js/input.js         键盘输入、边沿检测、方向指令缓冲(搓招识别)
js/audio.js         Web Audio 程序化音效与背景音乐
js/utils.js         数学/绘制工具
js/characters.js    6 名角色数据 + 像素人形骨架渲染器
js/stages.js        4 张地图绘制
js/fighter.js       战斗实例:物理/状态机/判定/绘制 + 飞行道具
js/ai.js            电脑对手
js/ui.js            所有界面与 HUD
js/game.js          主控制器:场景状态机、主循环、碰撞结算、回合流程、音效触发
```

调试:浏览器控制台执行 `DEBUG_HITBOX = true` 可显示命中盒/受击盒。
