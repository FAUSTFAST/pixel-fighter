# 动作重绘 v7（历史素材）

当前运行目录为 `../animation-v8/`。新版直接播放显式绘制的固定 PNG；原网格变形模块已删除。以下内容为旧版本设计记录。

## 历史版本 body-motion1（已撤下）

沿用角色待机原画身份与色板，重新设计完整步法：支撑脚锁地、摆动脚抬起、胯肩反向随动、护手与衣物延迟，停止时依次收脚。16 张目录预览姿势继续存在，运行中以真实位移在 128 个步相精度上采样；所有变形使用最近邻三角网格，不接入独立绘制移动素材。允许头部和上身随动，不再逐像素固定在同一屏幕位置。

拳脚前摇 / 回收增加屈肘、屈膝、胯肩时序、支撑腿承重与后脚跟发力。有效帧的拳脚终点保持原战斗距离，真实绘制像素继续参与近战接触检查。原始 PNG 不变。专项检查见 `scripts/check-body-motion.cjs`，完整回放见 `output/body-motion/body-motion.gif`。


## 历史版本 stable-walk2

移动统一继承各角色 `idle` 第 0 帧原画与胯部锚点，通过下半身运动生成每方向 16 个姿势采样。头部和上身逐字节保持一致；膝部抬脚 / 落脚、前后步法与收脚均由代码控制。原独立生成步法由于画风变化与锚点漂移已退出运行目录，下面的 steady-walk1 / contact1 仅作历史记录。加载器和回归检查会拒绝与待机不同源的移动图帧。原始 PNG 未修改。

攻击根位移和冲刺碰到对手身体时停止自身接近；未命中不提前推走对手。步态在镜头边界约束后更新。专项检查与原版回放见 `scripts/check-stable-walk.cjs`、`output/stable-walk/stable-walk.gif`。

## 稳步慢走 steady-walk1

前进、后退改为分开绘制的低抬脚步态：前进先迈前脚，再让后脚跟进；后退先退后脚，前脚随后，始终面向对手。原每方向 8 张，现疾风前进 12 张，其余方向各 16 张，共 188 张移动姿势。舍弃了初稿中的蹲姿、裁切帧和连在一起的图帧，不用重复帧凑足数量。

最终文件：疾风前进 `ryu-walk-forward-v5.png`（4×3），疾风 / 美琳 / 闪电后退 `*-walk-backward-v4.png`，其他前后步法 `*-walk-*-v3.png`（4×4）。准确的完整路径、帧顺序和摘要见 `identity-lock.json`。其余动作使用原已核对图集；总目录为 48 张图集、764 张姿势。

全部使用内置 imagegen。`standing-reference-prompts.json` 记录单人站姿参考的制作，`slow-walk-final-prompts.json` 记录步态绘制，`slow-walk-repair-prompts.json`、`ryu-walk-complete-prompt.json` 记录修正过程。初稿保留但不接入游戏。

PNG 原样保存。编目允许明确标注的 4×3 / 4×4 图集，按支撑脚鞋底对齐地面，不拉伸身体，拒绝缺帧和明显裁切。游戏缓存帧分辨率提高至原来的 1.5 倍；步法直接播放绘制姿势；contact1 攻击加入小幅胯肩局部变换，不使用叠影补帧。步频随实际位移，起步加速，停止后向下一个落脚姿势收脚。

本次使用内置 imagegen 重新绘制动作类别。初稿中部分图集误用了其他人物设计，现已用下列身份修正图替换。参考资料只用于研究动作姿势，游戏不加载第三方角色图集。

## 重画的动作库

| 图集 | 顺序 |
| --- | --- |
| walk | 前进、后退，保持面向对手 |
| stance | 待机、下蹲、站防、蹲防 |
| air | 前跳、后跳、空中拳、空中脚 |
| punch | 前手拳、重拳；苍月重击为斩击 |
| kick | 站立踢击、低踢与扫腿 |
| special | 施法或投掷、上升必杀、突进、投技 |
| reaction | 上段受击、腹部受击、击倒、起身 |

疾风采用紧凑拳架，美琳采用开放掌势和明确提膝，铁拳保持收下巴与双拳护面，闪电用较轻快的支撑脚转换，苍月让拔刀与髋部转动协调，贤者以开掌与衣摆随动表现施法。

## 播放与锚点

- 每张原图保留真实透明背景；按实际透明连通区域编目，错误网格或姿势需要补画。
- 角色在同一图集内使用统一比例。蹲姿、收膝、横躺不拉高到站立身高。
- 身体根部与地面锚点按图集和行确定，不逐帧按外框重新居中。发力时肩髋、衣摆和手脚的位移保留在绘制姿势中。
- 行走按实际位移播放，前后步法独立；出拳在有效帧开始时到达接触姿势，收招独立回收。
- 新绘横躺和起身直接播放，不再次旋转整个人物。抛投过程的位置仍由战斗逻辑驱动。
- 60 Hz 是游戏逻辑频率；实际独立绘制帧数由 manifest.json 和页内动作图鉴显示。不同强度及部分必杀共用相应新绘动作组。

## 文件

PNG 为生成结果原样复制，脚本只生成目录元数据。`prompts.json` 与 `pilot-prompt.txt` 保存初稿提示词。`catalog-report.json` 记录编目情况。`scripts/catalog-animation-v7.py` 校对素材摘要并严格分离透明区域；全部 6 人、每人 22 段 / 112 帧完整后才原子更新 `manifest.json`。`js/arcade-animation.js` 检查角色归属后按实际显示尺寸缓存帧。命中闪光保留原图，以 24% 浅色覆盖，避免角色瞬间变成纯白剪影。

## 实体接触 contact1

普通拳脚的有效范围由原画末端标记和当前胯肩采样决定，随后检查双方当前图帧的可见像素接触。末端目录见 `../../../js/strike-art.js`，采样见 `../../../js/strike-motion.js`。增加小幅地面蹬步，身体和墙壁参与约束；空中姿势与跳跃运动保持原有处理。波与能量技由相应可见效果判定。原始 PNG 未修改。
